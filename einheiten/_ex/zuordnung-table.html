Zuordnung-Tabelle — Radio-Matrix

Wann verwenden?

Die Zuordnungs-Tabelle eignet sich, wenn mehrere Zeilen jeweils eine Auswahl aus denselben Spaltenoptionen benötigen, zum Beispiel wenn Schülerinnen und Schüler für jedes EU-Organ eine Eigenschaft (supranational / intergouvernemental / national) bestimmen sollen. Der Typ ist übersichtlicher als einzelne Dropdown-Felder, wenn alle Zeilen dieselben Kategorien haben.

Interaktion

Pro Zeile wird ein Radio-Button gewählt; beim Klick auf "Überprüfen" wird jede Zeile mit dem in data-correct hinterlegten Wert verglichen.

JS-Modul

quiz-ext.js — Funktionen: PLK.selZT(el), PLK.chkZT(tableId, fbId), PLK.rstZT(tableId)

CSS-Klassen

  • .zt-table — Tabellen-Element; muss eine id haben
  • tbody tr[data-correct] — jede Datenzeile; data-correct = erwarteter Radio-Wert
  • tr.ok / tr.err — nach Prüfung durch PLK.chkZT()

State-Schlüssel

state.ab.zt[tableId][rowIndex] — gewählter Wert pro Zeile, indexiert nach Zeilenposition in tbody.
