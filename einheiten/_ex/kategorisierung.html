Kategorisierung — Kategorie-Buttons pro Item

Wann verwenden?

Kategorisierung eignet sich, wenn Schülerinnen und Schüler eine Liste von Aussagen oder Fakten einer von mehreren Kategorien zuweisen sollen, zum Beispiel "Demokratiegewinn / Effizienzgewinn / Demokratiedefizit" oder "Vorteil / Herausforderung". Besonders gut geeignet, wenn alle Items dieselben Kategorie-Buttons haben und es auf das Differenzieren ankommt.

Interaktion

Schülerinnen und Schüler klicken pro Item auf einen Kategorie-Button; beim Klick auf "Überprüfen" wird jedes Item mit dem in data-correct hinterlegten Kategorie-Wert verglichen.

JS-Modul

quiz-base.js — Funktionen: PLK.kS(button, cat), PLK.chkK(listId), PLK.retK(listId), PLK.rsK(listId)

HTML-Pattern

<!-- Kategorisierung — FILL: listId (= id auf .k-list), data-correct-Werte -->
<div class="k-list" id="auf1">

  <!-- FILL: data-correct = Wert der richtigen Kategorie; data-id muss eindeutig sein -->
  <div class="k-item" data-id="k1" data-correct="">
    <div class="k-text"><!-- FILL: Aussage --></div>
    <div class="k-btns">
      <!-- FILL: onclick-Wert muss mit data-correct der richtigen Items übereinstimmen -->
      <button class="k-btn" onclick="PLK.kS(this,'')"><!-- FILL: Label A --></button>
      <button class="k-btn" onclick="PLK.kS(this,'')"><!-- FILL: Label B --></button>
      <button class="k-btn" onclick="PLK.kS(this,'')"><!-- FILL: Label C --></button>
    </div>
  </div>

  <div class="k-item" data-id="k2" data-correct="">
    <div class="k-text"><!-- FILL: Aussage --></div>
    <div class="k-btns">
      <button class="k-btn" onclick="PLK.kS(this,'')"><!-- FILL: Label A --></button>
      <button class="k-btn" onclick="PLK.kS(this,'')"><!-- FILL: Label B --></button>
      <button class="k-btn" onclick="PLK.kS(this,'')"><!-- FILL: Label C --></button>
    </div>
  </div>

</div>

<div style="display:flex;gap:.5rem;flex-wrap:wrap;align-items:center;margin-top:1rem">
  <button class="btn btn-primary" onclick="PLK.chkK('auf1')">Überprüfen</button>
  <button class="btn btn-ghost btn-sm" id="auf1-retry" style="display:none" onclick="PLK.retK('auf1')">Falsche nochmal</button>
  <button class="btn btn-ghost btn-sm" onclick="PLK.rsK('auf1')">Zurücksetzen</button>
</div>

CSS-Klassen

  • .k-list — Container; id = aufgabeId für PLK.chkK()
  • .k-item — einzelnes Item; data-id eindeutig, data-correct = korrekter Kategoriewert
  • .k-text — Aussagetext
  • .k-btns — Zeile der Kategorie-Buttons
  • .k-btn — einzelner Kategorie-Button
  • .k-btn.selected — aktiv ausgewählt
  • .k-item.correct / .k-item.wrong — nach Prüfung

State-Schlüssel

state.ab.texts (indirekt via PLK._qs.kSel[itemId]) — gewählter Kategorie-Wert pro Item.
