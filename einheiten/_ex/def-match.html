Def-Match — Definition-Begriff Matching

Wann verwenden?

Definition-Match eignet sich, wenn Schülerinnen und Schüler Definitionen mit den dazugehörigen Fachbegriffen verbinden sollen. Anders als Zuordnung (links-rechts-Klick) wird hier beidseitig geklickt: zuerst eine Definition, dann ein Begriff (oder umgekehrt). Besonders geeignet für Glossar-Übungen mit 3 bis 6 Paaren.

Interaktion

Schülerinnen und Schüler klicken ein Element auf einer Seite, dann das passende auf der anderen Seite; einmal gepaarte Elemente sind gesperrt. Es gibt keine separate Check-Funktion: das Pairing ist der Abschluss-Schritt; Prüfung erfolgt via PLK.chkDM().

JS-Modul

quiz-lib.js — Funktionen: PLK.dmSel(el, side) (side: 'def' oder 'term'), PLK.chkDM(wrapId, fbId), PLK.rstDM(wrapId). Attribute: data-id auf jedem Element, data-correct-def auf jedem .dm-term = data-id der zugehörigen Definition.

HTML-Pattern

<!-- Def-Match — FILL: wrapId, data-id auf allen Elementen, data-correct-def auf .dm-term -->
<div class="dm-wrap" id="dm1">
  <div class="dm-cols">

    <!-- Linke Spalte: Definitionen -->
    <div class="dm-defs">
      <!-- FILL: data-id = eindeutiger Bezeichner der Definition -->
      <div class="dm-def" data-id="d1" onclick="PLK.dmSel(this,'def')"><!-- FILL: Definition A --></div>
      <div class="dm-def" data-id="d2" onclick="PLK.dmSel(this,'def')"><!-- FILL: Definition B --></div>
      <div class="dm-def" data-id="d3" onclick="PLK.dmSel(this,'def')"><!-- FILL: Definition C --></div>
    </div>

    <!-- Rechte Spalte: Begriffe -->
    <div class="dm-terms">
      <!-- FILL: data-id = eindeutiger Bezeichner des Begriffs
               data-correct-def = data-id der zugehörigen Definition -->
      <div class="dm-term" data-id="t1" data-correct-def="" onclick="PLK.dmSel(this,'term')"><!-- FILL: Begriff A --></div>
      <div class="dm-term" data-id="t2" data-correct-def="" onclick="PLK.dmSel(this,'term')"><!-- FILL: Begriff B --></div>
      <div class="dm-term" data-id="t3" data-correct-def="" onclick="PLK.dmSel(this,'term')"><!-- FILL: Begriff C --></div>
    </div>

  </div>

  <div style="display:flex;gap:.6rem;flex-wrap:wrap;margin-top:1rem">
    <button class="btn btn-primary" onclick="PLK.chkDM('dm1','dm1-result')">Überprüfen</button>
    <button class="btn btn-ghost btn-sm" onclick="PLK.rstDM('dm1')">Zurücksetzen</button>
  </div>
  <div class="mc-feedback" id="dm1-result" style="display:none;margin-top:.75rem"></div>
</div>

CSS-Klassen

  • .dm-wrap — Container; muss id haben
  • .dm-cols — zweispaltiges Layout
  • .dm-defs / .dm-terms — Spalten-Container
  • .dm-def — Definition-Element; data-id eindeutig
  • .dm-term — Begriff-Element; data-id eindeutig; data-correct-def = passende def data-id
  • .dm-def.dm-active / .dm-term.dm-active — aktiv ausgewählt
  • .dm-def.paired / .dm-term.paired — gepaart (gesperrt)
  • .dm-def.ok / .dm-term.ok — richtig nach Prüfung
  • .dm-def.err / .dm-term.err — falsch nach Prüfung

State-Schlüssel

state.ab.dm[wrapId] — Objekt mit {termId: defId} für alle gepaarten Terme.

Vollständiges Beispiel (Politik-LK)

<!-- EU-Organe und ihre Kernfunktionen -->
<div class="dm-wrap" id="dm1">
  <div class="dm-cols">
    <div class="dm-defs">

      <div class="dm-def" data-id="d3" onclick="PLK.dmSel(this,'def')">Wird direkt gewählt und übt demokratische Kontrolle über die Kommission aus.</div>
    </div>
    <div class="dm-terms">
      <div class="dm-term" data-id="t1" data-correct-def="d2" onclick="PLK.dmSel(this,'term')">Rat der EU</div>

      <div class="dm-term" data-id="t3" data-correct-def="d1" onclick="PLK.dmSel(this,'term')">Europäische Kommission</div>

    <button class="btn btn-primary" onclick="PLK.chkDM('dm1','dm1-result')">Überprüfen</button>

  </div>
  <div class="mc-feedback" id="dm1-result" style="display:none;margin-top:.75rem"></div>
</div>
