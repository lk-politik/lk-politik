Memory Card Game

Wann verwenden?

Zum Einüben von Zusammenhängen durch visuelles Gedächtnis: Institutionen ↔ Kompetenzen, Personen ↔ Ämter, Verträge ↔ Ziele. Stärkt Vernetzung stärker als reines Lesen.

Interaktion

Alle Karten liegen verdeckt. Zwei aufdecken — passen sie zusammen, bleiben sie offen (grün). Falsche Paare bleiben 2 Sekunden sichtbar, dann drehen sie sich zurück.

JS-Modul

quiz-lib2.js — Typ: data-type="memory-cards". Kein AB-Punkt.

HTML-Pattern (drei Modi)

<div class="aufgabe" data-type="memory-cards" data-id="auf4">

  <!-- Modus A: Glossar-Begriff ↔ Kompetenztext -->
  <div class="mc-pair"
       data-term="Exakter Glossar-Begriff"
       data-match="Kompetenztext"></div>

  <!-- Modus B: Person ↔ Amt -->
  <div class="mc-pair"
       data-person="dateiname-ohne-jpg"
       data-name="Vollständiger Name"
       data-match="Amtsbezeichnung"></div>

  <!-- Modus C: Vertrag / nicht-Glossar-Begriff ↔ Ziel -->
  <div class="mc-pair"
       data-label="Bezeichnung"
       data-match="Ziel / Inhalt"></div>

</div>

Attribute

  • data-term: Exakter Glossar-Begriff — Emoji wird automatisch aus _PLK_GLOSSARY geholt (konsistent mit fb-Tooltips)
  • data-person + data-name: Dateiname ohne .jpg (z.B. von-der-leyen → data/persons/von-der-leyen.jpg); Fallback: Initialen-Kreis (erste + letzte Initiale)
  • data-label: Nicht-Glossar-Bezeichnung; bekommt immer 📜
  • data-match: Text der grauen Gegenkarte (bei allen Modi)

       data-match="Wählt Gesetze mit, kontrolliert die Kommission, genehmigt den Haushalt."></div>
  <div class="mc-pair" data-term="Rat der EU"
       data-match="Vertritt die Mitgliedstaaten; beschließt Gesetze gemeinsam mit dem EP."></div>
  <div class="mc-pair" data-person="von-der-leyen" data-name="Ursula von der Leyen"
       data-match="Präsidentin der Europäischen Kommission"></div>
  <div class="mc-pair" data-label="Vertrag von Maastricht"
       data-match="Gründung der EU; Einführung der Unionsbürgerschaft (1992)."></div>
</div>
